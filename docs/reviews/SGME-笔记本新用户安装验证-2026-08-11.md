# SGME 笔记本新用户安装验证记录（2026-08-11）

> 类型：新用户（first-time user）视角全流程验证
> 环境：笔记本 192.168.10.141（独立新数据库，与生产库隔离），GitHub 私有仓拉取
> 结论：**安装 → 空库初始化 → 使用全链路可行**；新手体验 18 问题 → ST-22

## 1. 前置环境（新用户视角的起点）

- 笔记本：Windows 10，git 2.55 + GCM，**无 Python、无 Hermes、无 gh**
- 网络：GitHub 直连慢（代理失效），PyPI 直连正常（45.9 MB/s）

## 2. 安装流程验证

| 步骤 | 结果 | 发现 |
|---|---|---|
| git clone 私有仓 | ✅ GCM 浏览器授权一次，长期有效 | 需凭据（私有仓门槛，正常） |
| python -m venv | ⚠️ 需先有 Python | README 无 Python 安装指引（问题 #1） |
| pip install -e .[dev] | ✅ PyPI 直连秒级 | 无需离线包 |
| python -m sgme 首次启动 | ✅ 三库自动创建（memory/session/wiki），零手工初始化 | 默认 key 告警仅打印 |

## 3. 初始化与使用验证

- 空白库自动初始化：data/ 三库 + agent_keys.json 自动生成，无初始化步骤
- LLM 配置：DEEPSEEK_API_KEY 注入后 llm.available=true；未配置时 refine 走降级链最终 500（无友好提示——问题 #2）
- 全链路：append → refine（DeepSeek 秒级，无降级）→ inject（画像出内容）→ search（命中 + 溯源）✅
- 鉴权闭环补测：register 签发 → 新 key 使用 → 权限边界（agent 调 admin 403）→ 持久化 → 吊销 → 拒绝，全链路 ✅

## 4. Reasonix agent 视角审计（独立验证）

笔记本安装 Reasonix v1.23.0（DeepSeek key）后，以"新用户 agent"身份审查产出 **18 个问题**（详见 docs/audit/SGME-新手体验审计-2026-08-11.md）：
- 文档缺口 7：默认 key 未文档化、runbook 与实际配置脱节（旧模型名）、L0 格式无示例、双库/三库表述矛盾、环境变量表不全等
- 流程断点 7：向量检索静默降级（VOLC_API_KEY 缺）、inject 空画像无提示、LLM 全挂时长时间无反馈、append 不自动提炼未说明等
- 错误信息 4：403 无引导、inject 未知 mode 暴露绝对路径、422 英文与中文业务错误割裂等
- 配置 3：VOLC_API_KEY 硬前提无文档、占位符易误导、裸 python 命令 Windows 不适配

- **新手体验瓶颈在文档与提示**（18 问题），已在 ST-22 排期修复
