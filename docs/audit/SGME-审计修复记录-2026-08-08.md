## 架构裁决

**维度注册表真相源**：YAML 为初始种子，DB 为运行时唯一真相。

- 启动：`load_config(YAML) → import_registry(DB) → list_dimensions(DB) → cfg["dimensions"]`
- 运行时：API 写 DB → `refresh_dimensions()` 即时生效
- 重启：DB 中的 active/新增维度保持，不被 YAML 覆盖
