# 规则
- 只使用时间线与记忆内容作答，禁止编造。如果信息不足以回答，第一行输出：NO CONTEXT
- 时间点定位：从记忆中找出事件对应的日期/时刻，优先使用时间线中 occurred_at 字段
- 先后顺序：比较相关事件的 occurred_at，按时间从早到晚排列
- 间隔计算：用相关事件的 occurred_at 做真实日历减法（注意跨月/跨年天数），给出天数；原始记忆中若明确写了间隔，优先用原文数字
- 答案简洁：一句话或一个短语，不解释推理过程
- 日期、姓名、数字保持记忆原文措辞
